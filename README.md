# Thai Restaurant Office Orders

A Python application for managing Thai restaurant orders for office use.

## Overview
This application streamlines the process of organizing and managing group food orders from Thai restaurants.

## Features
- Order management system
- Menu item selection
- Order aggregation
- Cost calculation and splitting
- Order history

## Technology Stack
- Python 3.7+
- Streamlit or Flask (web framework)
- Database integration

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure restaurant data
4. Run the application
